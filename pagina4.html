  • Dominio:

    Un dominio en HTML es el nombre que identifica a una página web. Los nombres de dominio se utilizan en URLs para identificar a qué servidor pertenece una página web específica. El nombre de dominio consiste en una secuencia jerárquica de nombres (etiquetas) separados por puntos y que terminan con una extensión.

  • Sub dominio:

    En HTML, un subdominio no es una característica directamente implementable. Los subdominios son parte de la estructura de la dirección web (URL) y se configuran a nivel de servidor, no en el código HTML de la página.

  • URL:

    En HTML, una URL (Uniform Resource Locator) es una dirección que identifica un recurso específico en la web, como una página web, una imagen o un archivo.

  • DNS:

    En HTML, DNS se refiere al Sistema de Nombres de Dominio (Domain Name System), el cual no es un elemento de HTML en sí, sino un servicio fundamental para la navegación web

  • Hosting:

    El término "hosting" en HTML, o más precisamente en el contexto de la web, no se refiere a un elemento o propiedad de la lengua de marcado. Se refiere a un servicio de alojamiento web que permite almacenar y publicar los archivos de un sitio web en Internet

  • HTTP:

    HTTP, que significa Hypertext Transfer Protocol (Protocolo de Transferencia de Hipertexto), es el protocolo que permite la comunicación y transferencia de datos entre un cliente (como un navegador web) y un servidor web.

  • HTTPS:

    HTTPS en HTML significa Hypertext Transfer Protocol Secure. Es la versión segura de HTTP, el protocolo que utiliza HTML para transmitir datos a través de la web. En HTTPS, la información se cifra, lo que protege contra la interceptación y manipulación por terceros, asegurando una comunicación segura entre el navegador y el servidor web.

  • W3C:

    En HTML, W3C (World Wide Web Consortium) es la organización internacional que establece los estándares y especificaciones para el lenguaje HTML.

  • UTF-8:

    En HTML, UTF-8 es la codificación de caracteres más común, que se utiliza para representar texto en páginas web.

  • HTML5 y su esctructura:

    HTML5 es la última versión del Lenguaje de Marcado de Hipertexto (HTML), que se utiliza para estructurar el contenido de las páginas web.
